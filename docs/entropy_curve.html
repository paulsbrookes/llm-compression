Binary Entropy Function  H(p)

H(p) = −p·log2(p) − (1−p)·log2(1−p). This is the entropy (in bits) of a single coin flip with bias p — the minimum average bits per symbol needed to encode such a source, per Shannon’s source coding theorem. Move your mouse over the curve.

p = 0.500  →  H = 1.000 bits (maximum)
